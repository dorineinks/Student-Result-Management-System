
# Student Result Management System

## Project Description
The Student Result Management System is a Python-based application designed to manage student information, record academic scores, calculate results, and generate performance reports.

## Features
- Register new students.
- View all registered students.
- Search students by ID or name.
- Update student information.
- Delete student records.
- Record and update scores in five subjects.
- Calculate total scores and averages.
- Automatically assign grades.
- Generate individual student report cards.
- Sort students by average or name.
- View class performance statistics.
- Save class reports to a text file.
- Store and retrieve student records using JSON.

## Subjects
1. Mathematics
2. English
3. Biology
4. Chemistry
5. Physics

## Grading System

| Average Score | Grade |
|---|---|
| 70–100 | A |
| 60–69 | B |
| 50–59 | C |
| 45–49 | D |
| Below 45 | F |
